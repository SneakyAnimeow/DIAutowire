# DIAutowire

A source-generator-powered dependency injection autowiring library for .NET that removes boilerplate from DI registration and startup sequencing.

## Features

- **`[Autowire]`** — Source-generates DI registrations automatically
- **`[DeclareDIComponentType]`** — Generates custom component-type attributes (e.g. `[Service]`, `[Repository]`)
- **`[DIComponent]` / built-in types** — Triggers automatic interface generation (`IClassName`)
- **`[Autorun]`** — Marks methods for execution at startup with priority control
- **`ServiceResolver<T>`** — Helper for resolving services with named and scoped support

---

## Getting Started

Reference both `DIAutowire` and `DISourceGenerator` (as an Analyzer) in your project:

```xml
<ItemGroup>
  <ProjectReference Include="..\DIAutowire.csproj" />
  <ProjectReference Include="..\DISourceGenerator\DISourceGenerator.csproj"
                    OutputItemType="Analyzer" ReferenceOutputAssembly="false" />
</ItemGroup>
```

Register all autowired services and launch autorun methods in `Program.cs`:

```csharp
var builder = WebApplication.CreateBuilder(args);
builder.Services.DIAutowire(); // registers all [Autowire]-marked classes

var app = builder.Build();
await app.Services.LaunchAutorun(); // runs all [Autorun]-marked methods

app.Run();
```

## Autowiring

### `[Autowire]`

Place on any `partial class` to register it with DI. The source generator creates an `IClassName` interface and emits an `AddScoped<IClassName, ClassName>()` (or other lifetime) call.

```csharp
[Autowire]                              // Scoped (default)
[Autowire(ServiceLifetime.Singleton)]   // Singleton
[Autowire(ServiceLifetime.Transient)]   // Transient
[Autowire("my-impl")]                   // Named (keyed) — AddKeyedScoped
[Autowire("my-impl", ServiceLifetime.Singleton)] // Named + lifetime
```

The class **must** be `partial` for the generated `IClassName` interface to be wired in automatically.

```csharp
/// <summary>
/// Processes payment transactions.
/// </summary>
[Autowire(ServiceLifetime.Scoped)]
public partial class PaymentService
{
    public decimal ProcessPayment(decimal amount) => amount * 0.98m;
}
```

The generator produces:

```csharp
// <auto-generated/>

/// <summary>
/// Processes payment transactions.
/// </summary>
public interface IPaymentService
{
    decimal ProcessPayment(decimal amount);
}

public partial class PaymentService : IPaymentService { }
```

> XML doc comments from the class and its members are automatically inherited by the generated interface.

## Component Types

### Built-in types

Three component-type attributes are included out of the box:

| Attribute | Inherits |
|---|---|
| `[Service]` | `DIComponentAttribute` |
| `[Component]` | `DIComponentAttribute` |
| `[Repository]` | `DIComponentAttribute` |

These are semantic markers. When combined with `[Autowire]`, the class is both labelled and registered.

```csharp
[Service]
[Autowire(ServiceLifetime.Scoped)]
public partial class OrderService { ... }
```

### `[DeclareDIComponentType]`

Declare a custom component type at the assembly level. The source generator creates a new attribute class inheriting from `DIComponentAttribute`.

```csharp
// AssemblyInfo.cs or Program.cs
[assembly: DeclareDIComponentType("Adapter")]
[assembly: DeclareDIComponentType("Gateway")]
```

This generates:

```csharp
// <auto-generated/>
public class AdapterAttribute : DIComponentAttribute { }
public class GatewayAttribute : DIComponentAttribute { }
```

You can then use them just like the built-in types:

```csharp
[Adapter]
[Autowire(ServiceLifetime.Transient)]
public partial class HttpGatewayAdapter { ... }
```

## Autorun

### `[Autorun]`

Marks a **method** to be automatically invoked during `LaunchAutorun()`. Discovered via reflection at startup.

```csharp
[Autowire(ServiceLifetime.Singleton)]
public partial class CacheWarmupService
{
    [Autorun(AutorunPriority.Critical)]
    public async Task WarmupCaches()
    {
        // runs before anything else
    }

    [Autorun(AutorunPriority.Low)]
    public void LogStartup()
    {
        Console.WriteLine("Service started.");
    }
}
```

Methods may be `void`, `Task`, or `ValueTask`. Both sync and async methods are supported.

### `AutorunPriority`

| Value | Order |
|---|---|
| `Critical = 3` | First |
| `High = 2` | Second |
| `Default = 1` | Third |
| `Low = 0` | Last |

> **Singleton services** are resolved from the **root provider**. Scoped and Transient services run inside a temporary scope that is auto-disposed after all autoruns complete.

### `LaunchAutorun()`

Extension method on `IServiceProvider`:

```csharp
await app.Services.LaunchAutorun();
```

## ServiceResolver\<T\>

A helper injectable class for resolving DI components with flexible strategies.

Registered automatically by `DIAutowire()` via `AddTransient(typeof(ServiceResolver<>))`.

```csharp
[Autowire(ServiceLifetime.Singleton)]
public partial class OrderProcessor
{
    private readonly IPaymentService _payment;

    public OrderProcessor(ServiceResolver<IPaymentService> resolver)
    {
        // Resolve the default (unkeyed) implementation
        _payment = resolver.Resolve();

        // Resolve a named (keyed) implementation
        _payment = resolver.Resolve("stripe");

        // Resolve with a new auto-disposable scope
        using var scoped = resolver.ResolveScoped();
        scoped.Component.ProcessPayment(100m);

        // Resolve a named implementation in a new scope
        using var namedScoped = resolver.ResolveScoped("stripe");
        namedScoped.Component.ProcessPayment(100m);
    }
}
```

### `ScopedResult<T>`

Returned by `ResolveScoped()`. Holds the resolved component and disposes the scope when `Dispose()` is called. Use with `using` statements for correct lifetime management.

```csharp
using var result = resolver.ResolveScoped("my-key");
var value = result.Component.DoWork();
// scope is disposed here
```

```
│       └── AutorunAttribute.cs          # [Autorun] — marks methods for startup execution
├── Core/
│   └── BuiltInDIComponentTypes.cs       # Declares built-in [Service], [Component], [Repository]
├── DISourceGenerator/

├── Enums/
│   └── AutorunPriority.cs               # Low / Default / High / Critical
├── Extensions/

│   └── SemaphoreSlimExtensions.cs       # Async locking helper
├── Helpers/
│   ├── ServiceResolver.cs               # ServiceResolver<T> + ScopedResult<T>

└── DIAutowire.Tests/                    # xUnit test project
    ├── AutowireTests.cs
    ├── LaunchAutorunTests.cs
    └── ServiceResolverTests.cs
```
